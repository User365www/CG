# Лабораторная работа №2, вариант 10

- Глобальная пороговая обработка: метод Отсу и итеративный метод (сравнение).
- Нелинейная фильтрация по порядковым статистикам: медиана, минимум, максимум (окно 3×3 или 5×5).

Алгоритмы находятся в `processing.py`, запуск сайта в `main.py`, страница в `templates/index.html`.
Изображения для демонстрации находятся в `images/`.

## Запуск

Из папки `lab2`:

```
python -m pip install -r requirements.txt
python main.py
```

В браузере открыть http://127.0.0.1:5000
