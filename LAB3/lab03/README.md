# Лабораторная работа №3 — веб-приложение

Минимальное веб-приложение на Flask для демонстрации четырёх базовых растровых алгоритмов.

## Запуск
```bash
python -m pip install -r requirements.txt
python main.py
```
Либо в Windows запустите `run.bat` двойным щелчком. Откройте в браузере http://127.0.0.1:5000

## Реализовано
- Пошаговый алгоритм построения отрезка.
- ЦДА (DDA).
- Алгоритм Брезенхема для отрезка.
- Алгоритм Брезенхема для окружности.
- Координатная сетка, оси X/Y, целочисленные подписи и масштаб.
- Измерение среднего времени выполнения каждого алгоритма (100 повторений, без учёта отрисовки).

## Координатная сетка
Целочисленная координата (x, y) соответствует узлу дискретной сетки:
screen_x = center_x + x * scale
screen_y = center_y - y * scale
Знак минус нужен потому, что в браузерном Canvas ось Y направлена вниз.

## Важно для структуры проекта
Папка `templates` должна находиться рядом с `main.py` и `raster_lab`, а не внутри `raster_lab`. Путь к шаблонам задан явно через `Path(__file__)`, поэтому приложение корректно находит HTML независимо от текущей рабочей папки.
